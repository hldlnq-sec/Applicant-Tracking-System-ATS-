## 1.1 Реализация основный структур

Для удобства работы с вакансиями создана специальная структура следующего вида:

```
typedef struct
{
int ID;
char title[MAX_NAME];
char company[MAX_NAME];
double salary;
char requests[MAX_STRING];
Date CreationDate;
} Vacancy;
```

Она содержит следующие поля соответственно:

-   уникальный идентификатор (целочисленное значение);
-	название должности, компании (строка);
-	зарплата (вещественный тип, для учета различных валют);
-	требования (строка);
-	дата публикации (специальная структура)


Для удобства работы с соискателями создана специальная структура следующего вида:

```
typedef struct
{
int ID;
char FullName[MAX_NAME];
char skills[MAX_STRING];
double salary;

} Pretender;
```

Структура содержит следующие поля соответственно:

-	уникальный идентификатор (целочисленное значение);
-	ФИО соискателя (строка);
-	навыки (строка);
-	желаемая зарплата (вещественный тип, для учета различных валют);
-	дата регистрации (специальная структура).

Для удобной реализации даты дополнительно создана структура даты следующего вида:

typedef struct

Структура содержит в себе информацию о дате создания вакансии или анкеты соискателя (вида ДД.ММ.ГГГГ).
Также для удобства работы во время разработки программы структурные типы данных переименованы согласно с целью их создания.

## 2.1 Быстрая сортировка

Традиционный алгоритм быстрой сортировки подразумевает собой

выбор опорного элемента. От выбора опорного элемента не зависит корректность алгоритма, но в отдельных случаях может сильно зависеть его эффективность. Сравнение всех остальных элементов с опорным и перестановка их так, чтобы разбить массив на два непрерывных отрезка, следующих друг за другом: элементы меньшие и большие опорного. Для отрезков «меньших» и «больших» значений выполнить рекурсивно ту же последовательность операций, если длина отрезка больше единицы.

В программе алгоритм быстрой сортировки реализован при помощи

функции quickSortVacanciesSalary(FILE*, int, int). Функция

принимает в качестве аргументов указатель на файл, в котором производится замена, а также индексы краев интервала, в пределах которого работает функция. Функция не возвращает никаких данных в результате совей работы.

Алгоритм: 1 Открытие файлов для работы и проверка успешности открытия 2 Определение общего количества записей в файле 3 Обращение к функции быстрой сортировки: Расчет позиции среднего элемента, который станет опорным. Разбиение: перераспределение элементов в файле таким образом, что

элементы, меньшие опорного, помещаются перед ним, а большие или равные после опорного.

Рекурсивно применить первые два шага к двум «подмассивам» слева и

справа от опорного элемента. Рекурсия не применяется к массиву, в котором

- только один элемент или отсутствуют элементы. 4 Вывод сообщения об успешности выполнения

- 5 Закрытие файлов, с которыми работала функция

- 2.2 Сортировка выбором

Наиболее естественный алгоритм. При сортировке выбором из массива

выбирается элемент с наименьшим значением и обменивается с первым элементом. Затем из оставшихся n-1 элементов снова выбирается минимальный и обменивается со вторым элементом и так далее.

В программе алгоритм сортировки методом простого выбора реализован

при помощи функции sortVacanciesByDateSelection(). Функция не

принимает никаких аргументов и не возвращает никаких значений. Весь ее

9


функционал заключается в сортировке вакансий по хронологии (день/месяц/год).

Алгоритм:

- 1 Открытие файлов для работы и проверка успешности открытия

- 2 Определение общего количества записей в файле

- 3 Внешний цикл от 0 до n-1 (текущая позиция i)

- 4 Установка минимального значения на элемент i

- 5 Внутренний цикл от i+1 до n (поиск элемента для замены)

- 6 Считывание двух элементов и их сравнение по признаку

- 7 Если найденный минимальный элемент не равен текущей позиции, то они меняются местами

- 8 Вывод сообщения об успешности выполнения;

- 9 Закрытие файлов, с которыми работала функция

## 2.3 Сортировка вставками

На каждом шаге алгоритма сортировки выбирается один из элементов

входных данных и помещается в нужную позицию в уже отсортированной последовательности до тех пор пока набор входных данных не будет исчерпан.

В программе алгоритм сортировки вставками реализован при помощи

функции sortPretendersByDateInsertion(). Функция не принимает

никаких аргументов и не возвращает никаких значений. Весь ее функционал заключается в сортировке соискателей по хронологии (день/месяц/год).

Алгоритм:

- 1 Открытие файлов для работы и проверка успешности открытия

- 2 Определение общего количества записей в файле

- 3 Если в файле менее двух записей, то сортировать нечего

- 4 Читаем текущий элемент, который нужно вставить (опорный)

- 5 Читаем элемент слева для первичного сравнения

- 6 Сдвигаем элементы вправо, пока не найдем место для pret_1

- 7 Сдвигаем pret_2 на одну позицию вправо

- 8 Сброс буфера после записи

- 9 Вставляем сохраненный опорный элемент (pret_1) на освободившееся место

- 10 Очистка буфера перед новой итерацией

- 11 Вывод сообщения об успешности выполнения

- 12 Закрытие файлов, с которыми работала функция

## 3 АЛГОРИТМЫ ПОИСКА

В курсовой работе реализованы два алгоритма поиска данных:

## 3.1 Линейный поиск

Простейший алгоритм поиска, эффективен в массивах с небольшим

количеством элементов, при этом элементы могут быть не отсортированы и не упорядочены. Алгоритм последовательно сравнивает все элементы с ключевым значением до тех пор, пока не достигнет конца.

В программе алгоритм линейного поска реализован в функции

linearSearchPretenderSalary(). Ее функционал заключается в поиске всех соискателей, чьи зарплатные ожидания не превышают заданный пользователем порог. Функция не принимает никаких аргументов и не возвращает никаких значений.

Алгоритм:

- 1 Открытие файлов для работы и проверка успешности открытия

- 2 Считывание порога зарплат от пользователя

- 3 Запуск цикла пока программа не достигнет конца файла

- 4 Сравнение зарплатных ожиданий текущего соискателя с ключом, в случае выполнения условий вакансия выводится на экран

- 5 Вывод сообщения об успешности выполнения

- 6 Закрытие файлов, с которыми работала функция

## 3.2 Бинарный поиск

Бинарный поиск – это более эффективный метод поиска, который можно

применять только к упорядоченному списку. Он делит список на половины и использует сравнения для определения, содержится ли искомый элемент в левой или правой половине списка, после чего поиск продолжается в соответствующей половине.

В программе алгоритм бинарного поиска реализован в функциях

binarySearchVacancyTitle(void),

binarySearchPretenderID(void). Их функционал заключается в

осуществлении поиска объекта по определенному признаку. Функции бинарного поиска являются вспомогательными и возвращают позицию в файле объекта, который соответствует ключу.

Алгоритм:

- 1 Открытие файлов для работы и проверка успешности открытия

- 2 Определение общего количества записей в файле

- 3 Быстрая сортировка файла по определенному признаку

- 4 Считывание ключа для поиска (название или идентификатор)

binarySearchVacancyID(void),


- 5 Деление отрезка поиска напополам

- 6 Сравнение ключа со средним элементом

- 7 Повторение пунктов 5-6 для половинных отрезков(левый, если ключ меньше значения, а правый – больше)

- 8 Проверка, чтобы элемент был найден в списке

- 9 Вывод сообщения об успешности выполнения

- 10 Закрытие файлов, с которыми работала функция

сдвигом последующих элементов и последующим усечением файла.

В программе для реализации такой возможности реализованы две

функции: deleteVacancy(void) – для файла вакансий,

deletePretender(void) – для файла соискателей. Данные функции не принимают никаких аргументов и не возвращают никаких значений.

Алгоритм работы:

- 1 Бинарный поиск индекса удаляемого элемента по его идентификатору

- 2 Открытие файлов для работы и проверка успешности открытия

- 3 Запуск цикла от найденного индекса до конца файла

- 4 Пошаговый сдвиг каждой записи на одну позицию назад

- 5 При копировании производится декремент ID каждой перемещаемой записи для сохранения непрерывности нумерации

- 6 Вызов системной функции _chsize для уменьшения физического размера файла на величину одной структуры

- 7 Закрытие файлов, с которыми работала функция

принимают никаких аргументов и не возвращают никаких значений.

- Алгоритм работы: 1 Бинарный поиск индекса удаляемого элемента по его идентификатору 2 Открытие файлов для работы и проверка успешности открытия 3 Считывание пункта меню для редактирования 4 Ввод новых данных для записи 5 Перезапись объекта в базе данных

- 6 Закрытие файлов, с которыми работала функция
