# Applicant-Tracking-System-ATS-

### Курсовой проект: Система подбора вакансий

Консольное программное средство на языке C/C++, разработанное в рамках курсовой работы в УО «БГУИР» (Факультет информационных технологий и управления, кафедра ВМиП). 

Программа предназначена для автоматизации процесса сопоставления профилей соискателей и открытых вакансий. Работа с базой данных реализована через создание и обработку **бинарных файлов** в режиме CLI (консоли). 

### Основной функционал

### 1. Управление данными (CRUD)

* Создание нового бинарного файла базы данных.
* Просмотр существующих записей.
* Добавление новых записей соискателей/вакансий в файл.
* Редактирование параметров существующих записей.
* Удаление выбранных записей из файла.
* Экспорт и генерация отчетов в читаемом текстовом формате (.txt).

### 2. Реализованные алгоритмы поиска

* **Линейный поиск:** по желаемой заработной плате соискателя.
* **Бинарный поиск:** по названию должности вакансии (требует предварительной сортировки).
* **Комплексный критерий:** поиск вакансий по соответствию желаемой зарплаты и ключевых навыков соискателя (с последующей сортировкой по дате публикации).

### 3. Реализованные алгоритмы сортировки

* **Быстрая сортировка (Quick Sort):** по уровню заработной платы вакансии.
* **Сортировка выбором (Selection Sort):** по дате публикации вакансии.
* **Сортировка вставками (Insertion Sort):** по дате регистрации соискателя.

### 4. Аналитика и статистика

* Формирование списка соискателей, зарегистрированных позже указанной даты, чьи профессиональные навыки полностью или частично удовлетворяют требованиям вакансий.

### Структуры данных

Программа оперирует двумя основными сущностями, сохраняемыми в бинарный формат: 

### Вакансия (Vacancy)

* Уникальный идентификатор (ID)
* Название должности
* Название компании
* Заработная плата
* Требования к кандидату
* Дата публикации

### Соискатель (Candidate)

* Уникальный идентификатор (ID)
* ФИО соискателя
* Профессиональные навыки
* Желаемая заработная плата
* Дата регистрации

### Среда разработки и компиляция

* **Язык программирования:** C / C++
* **Стандарт языка:** C99 / C++11 (в зависимости от финальной сборки)
* **Режим работы:** Консольный (CLI)

### Сборка проекта с помощью GCC

```bash
gcc -o job_system main.c -Wall -Wextra -std=c99
```

### Запуск программы

```bash
./job_system
```
